# Wallora AI — Mobile (Flutter)

Android application ID / iOS bundle ID: `ai.wallora.app`.

## Run

```powershell
Copy-Item config/dev.example.json config/dev.json   # local values; gitignored
flutter pub get
flutter run --dart-define-from-file=config/dev.json
```

`config/*.json` hold **public identifiers only** (API URL, RevenueCat public SDK keys, AdMob unit IDs). Anything compiled into the app can be extracted, so private keys never go here.

## Checks

```powershell
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
```

## Platform prerequisites
- Android builds need Android Studio (SDK + platform tools) and JDK 17.
- iOS builds need macOS with Xcode.
- Firebase config files (`google-services.json`, `GoogleService-Info.plist`, `firebase_options.dart`) are generated by `flutterfire configure` and gitignored.
