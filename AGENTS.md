# AGENTS.md — rules for anyone (human or AI) changing this repository

## Ground rules
1. Read [docs/TASKS.md](docs/TASKS.md) and the relevant planning doc in [docs/](docs/) before changing code. Work one approved phase at a time.
2. Keep changes small and reviewable. Preserve existing work. Explain destructive commands before running them.
3. **Never** add real credentials, tokens or keys to the repository, logs, tests or examples. Example files hold placeholders only.
4. **Never** make paid API calls, create paid cloud resources, publish apps or deploy publicly without the owner's explicit approval. CI and tests always use `IMAGE_PROVIDER=fake`.
5. Never claim a test, build or integration works unless it was run and its output inspected. Record honest status in TASKS.md (`[x]` only with evidence).
6. Never weaken or skip a failing test to make a build pass.
7. Use current official documentation for external APIs. Mark uncertainties instead of inventing APIs.

## Architecture invariants
- The server is the source of truth for credits, entitlements, admin roles and purchases. Client claims are never trusted.
- Credit mutations happen in a single DB transaction that holds the `credit_accounts` row lock. `credit_ledger` and `audit_logs` are append-only.
- Generation requests require an `Idempotency-Key`.
- User prompts and uploads are private by default and are never logged.
- Only offer AI capabilities the configured provider actually reports.

## Per-package commands (all must pass before a phase is reported done)

| Package | Format | Lint / types | Tests |
|---------|--------|--------------|-------|
| backend | `py -m uv run ruff format --check .` | `py -m uv run ruff check .` · `py -m uv run mypy` | `py -m uv run pytest` |
| mobile | `dart format --output=none --set-exit-if-changed lib test` | `flutter analyze` | `flutter test` |
| admin | `npm run format:check` | `npm run lint` · `npm run typecheck` | `npm test` · `npm run build` |

## Conventions
- **Backend**: modules under `app/modules/<context>/{models,schemas,repository,service,router}.py`. UTC `timestamptz`. UUIDv7 IDs. RFC 9457 errors. Ruff + mypy strict.
- **Mobile**: feature-first `lib/features/<feature>/{data,domain,presentation}`. All user-visible strings in ARB files. Semantics labels on interactive and image widgets. Design tokens only, no ad-hoc colours or spacing.
- **Admin**: the server enforces every permission. UI checks are cosmetic. No secrets in `NEXT_PUBLIC_*`.
- Commits: imperative mood, one logical change per commit.

`admin/AGENTS.md` adds Next.js-version-specific guidance that's generated by Next.js.
